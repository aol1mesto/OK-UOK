# ОК-УОК — Личный кабинет

Базовый макет личного кабинета сотрудника службы контроля качества.

## Стек

- React + TypeScript (Vite)
- Tailwind CSS
- React Router
- Lucide Icons

## Запуск

```bash
npm install
npm run dev
```

## Навигация

| Раздел | Путь | Доступ |
|--------|------|--------|
| Главная (дашборд) | `/` | Все |
| Мои проверки / Отчёты | `/inspections` | Все |
| Предприятия (фильтр) | `/enterprises` | Менеджер, суперадмин |
| Настройки профиля | `/profile` | Все |

Роль демо-пользователя задаётся в `src/data/mockUser.ts`.
